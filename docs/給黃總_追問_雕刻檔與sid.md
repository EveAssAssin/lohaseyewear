# 一、雕刻檔的位置資訊要放哪裡?(最擋住)

v1.2 附錄二第②點寫:

> 雕刻檔 URL 放在 `main.design.engraving_url`,商城會隨訂單一路保存,
> 並顯示於商城後台訂單頁供人員下載進行雕刻。

這裡有一段落差:**SVG 只有圖案本身,沒有「要刻在鏡片哪個位置、多大」的資訊。**

同一張招財貓,刻在右鏡片外上角 8mm 見方,和刻在左鏡片正中央 20mm 見方,
是完全不同的成品。客人在官網拖曳決定的正是這件事。

## 我方需要知道的其實是一句話

**雕刻人員拿到那個 SVG 之後,是怎麼決定刻在哪裡、多大的?**

知道實際作業方式,我方才能產出對的檔案。目前想得到三種可能,請圈選或直接說明:

### 甲、SVG 檔本身就要排好版

官網輸出的不是單純圖案,而是「已按最終位置與大小排好、可直接送進雕刻軟體」的檔案。

若採此案,請告知三件事,否則我方做出來的檔案座標對不上:

1. **座標原點**以什麼為準?(鏡框外框左上角?鏡片中心?)
2. **鏡框輪廓要不要一起畫進 SVG** 當定位參考?
3. **尺寸單位**是 mm 還是 px?若是 px,一個單位對應多少實際尺寸?

### 乙、另外帶位置參數

`main.design` 增加 `placement` 區塊,由雕刻人員照數值定位:

```json
"placement": {
  "lens": "right",
  "scale": 0.12,
  "x": 0.68,
  "y": 0.38,
  "basis": "product_image"
}
```

`scale` / `x` / `y` 皆為**商品圖寬高的比例**,與解析度無關;`lens` 為 `right` / `left`(以配戴者為準)。

### 丙、只傳 `design_id`,雕刻人員上官網後台查

`cart/push` 只帶 `design_id`,我方另做一個門市/雕刻查詢頁,
輸入編號即可看到位置示意圖與尺寸標註。**對貴方改動最小。**

# 二、無規格商品的 `sid` 要傳什麼?

v1.2 附錄 A3 仍寫「加入購物車時需要商品 `nid` ＋ 規格 `sid` 的組合」。

但我方以 `can_design_only: 1` 取得的 **7 件可文創商品,`specifications` 全部是空陣列**
(`nid` 2612 / 2287 / 2286 / 2285 / 2284 / 2283 / 2282,皆為造型太陽眼鏡 NT$990)。

請問無規格商品應該:

- 省略 `sid` 欄位
- 傳 `null`
- 或傳 `0`

我方目前實作為「有規格才帶 `sid`,沒有就不帶」。若與貴方預期不同,
`cart/push` 第一次呼叫就會失敗,請告知正確做法。
