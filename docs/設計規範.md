# LOHAS 官網設計規範(Design Tokens 與共用元件)

> 2026-11-23 建立。背景與現況數據見 `docs/UI盤點報告_20261123.md`
> (`docs/*盤點*.md` 已 gitignore,只在本機,不進公開 repo)。
> 這份是「寫新東西時照著用」的規範;舊頁面依盤點報告的階段逐步換,不要一次大改。

## 一、檔案

| 檔案 | 內容 | 誰載入 |
|---|---|---|
| `css/lohas-tokens.css` | 所有 token(顏色、字級、間距、圓角、陰影、層級、動態)+ reset | 幾乎全站 |
| `css/lohas-base.css` | header、nav、footer、cookie banner、`.btn-primary` | 前台 |

| `js/lohas-ui.js` + `css/lohas-ui.css` | `LohasUI.alert / confirm / prompt / toast`(CSS 由 JS 自動載入) | 後台、會員中心、加工中心、門市/學生/感謝祭頁(預約彈窗) |

改了任何一支,**用到它的頁面 `?v=` 都要換**。

規則:
- **不要寫純灰**(#333、#666、#888、#999)。品牌是暖色系,純灰在米色底上會偏冷偏髒 → 用 `--text-*`。
- **token 的語意要對得上用途**:文字色 token 只拿來當文字色,邊框 token 只當邊框。
  值剛好一樣也不要混用,否則日後調文字色會連帶改到不相干的背景。
- **`--warn` 在白底上對比只有 3.1**:小字請用 `--warn-strong`,原色留給圖示、邊框、大字。
- 活動頁(年終、學生、生日、聯名)可以有自己的主題色(`--ye-*`、`--st-*`…),
  但文字、邊框、圓角請繼承全域 token。

## 三、提示與確認框:`LohasUI`

取代瀏覽器原生的 `alert` / `confirm` / `prompt`。頁面只要在其他 JS **之前**載入 `js/lohas-ui.js`,
樣式(`css/lohas-ui.css`)會自動跟著載入;沒載 `lohas-tokens.css` 的頁面也能用(CSS 都有備用值)。

```js
await LohasUI.alert('儲存失敗:' + err.message);           // 要按確定才關
if (!(await LohasUI.confirm('確定刪除?\n\n無法復原'))) return; // 取消 → false
const name = await LohasUI.prompt('輸入名稱:', '預設值');    // 取消 → null
LohasUI.toast('已儲存', 'ok');                              // 不擋流程,幾秒後自己消失
LohasUI.toast('上傳失敗', 'error');
```

🚨 **一定要 `await`**。原生 `confirm()` 是同步的,這裡回傳 Promise ——
`if (!LohasUI.confirm(x)) return;` 少了 `await`,Promise 永遠是 truthy,
**按「取消」也會照樣刪下去**,而且不會有任何錯誤訊息。
所在的函式因此必須是 `async`。

什麼時候用哪個:

| 情況 | 用 |
|---|---|
| 成功(已儲存、已刪除、已複製) | `toast(…, 'ok')` |
| 失敗、驗證錯誤、要人看清楚的長訊息 | `alert` |
| 刪除、上下架、放行、登出 | `confirm` |

行為:
- 訊息裡的 `\n` 會照樣換行。
- 訊息含「刪除、無法復原、永久、停權、移至垃圾桶、覆蓋」→ 確定鍵變紅色,
  **預設焦點在「取消」**(誤按 Enter 不會刪東西)。可用 `{ danger: true/false }` 強制。
- Esc = 取消;Enter = 確定(中文輸入法選字的 Enter 不算);Tab 鎖在框內。
- 點背景:確認/輸入框當成取消;單純提示框不關(免得誤觸漏看錯誤)。
- 同時叫出好幾個會排隊,一次一個。
- 手機(≤480px)從底部彈出,按鈕上下排滿寬。

## 四、後台:不要再寫 `style=""`

`admin-portal.html` 原本的行內樣式已搬到 `css/admin-portal-ui.css`(2026-11-23,畫面零差異)。
新寫的後台 HTML 直接用那支檔案的 class:

- `ad-*`:有名字的區塊,例如 `ad-m-input`(會員彈窗輸入框)、`ad-m-btn-ghost`、`ad-m-error`、`ad-empty-lg`
- `adu-*`:單一屬性的小工具,例如 `adu-mw-280`(max-width 280px)、`adu-mb-18`、`adu-gap-8`

例外:`display` 留在標籤上(JS 靠 `el.style.display` 切換)。

會員中心同理:`member-portal.html` → `css/member-portal-ui.css`(`mp-*` / `mpu-*`)。

後台專用的具名顏色在 `css/admin-portal.css` 開頭的 `:root`(`--ad-danger`、`--ad-feat*`、`--ad-m-*`、`--ad-hint`…),
新寫後台樣式請用這些名字,不要再寫色碼。
⚠ `--status-*`、`--lohas-tip` 定義在 `.ad` 上,掛在 body 底下的彈窗讀不到;要在那裡用,請改用 `:root` 的名字。

## 五、新元件命名

沿用 `lohas-components.css` 既有規則:通用元件一律 `.lohas-*` 前綴,
變體用 `--`(例:`.lohas-dlg-btn--danger`)。不要再新增頁面專屬的按鈕 class。

## 六、改舊頁面時

1. 先 `git fetch` —— 商城 / App 工程方也會改同一批檔案。
2. 芽芽教學(`yaya-*-guide.js`)靠 class / id 找元素:`case.html`、`cloth.html`、`custom.html`
   的 class 要「加」不要「換」,換了要同步改教學的 `sel`。
3. 批次換色用 Python(`encoding='utf-8'`、`newline=''` 保留原本換行),**不要用 PowerShell**。
4. 換完 `git diff` 逐檔看,桌機 + 手機截圖比對。
